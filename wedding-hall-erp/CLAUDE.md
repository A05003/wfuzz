# دور Claude في مشروع نظام إدارة قاعة الأفراح والمناسبات

نبني نظام ERP لإدارة قاعة أفراح. التزم بالقواعد:

1. ابنِ مرحلة واحدة فقط في كل مرة، ولا تستبق المراحل القادمة.
2. بعد كل مرحلة: لخّص ما تم + طريقة التجربة + القرارات المطلوبة، ثم انتظر الموافقة.
3. اسأل إذا كان شيء غير واضح بدل الافتراض.
4. الواجهات بالعربية RTL بنمط ألوان موحّد (brand).
5. Zod للتحقق من كل مدخل، وحماية كل صفحة وAPI بالصلاحيات.

## Stack
Next.js 15 (App Router) + TypeScript + Tailwind 3 + Prisma 6 (SQLite محلياً) + Auth.js v5 + Zod.

## أوامر
- `npm run db:setup` إنشاء القاعدة + بيانات تجريبية (`db:reset` يمسح البيانات — يشغّله المستخدم يدوياً فقط)
- `npm run dev` تشغيل | `npm test` اختبارات | `npm run lint` فحص الأنواع
